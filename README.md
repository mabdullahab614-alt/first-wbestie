# 🛍️ My Store — E-Commerce Product Listing Page

A responsive **E-Commerce Product Listing Page** built using only **HTML and CSS** (no frameworks — no Bootstrap, no Tailwind).

🔗 **Live Demo:** [mabdullahab614-alt.github.io/first-wbestie](https://mabdullahab614-alt.github.io/first-wbestie/)

---

## 📋 Overview

This project displays a clean, professional product listing page with a header, search bar, category navigation, and product cards — fully responsive across desktop, tablet, and mobile.

## ✨ Features

- Semantic HTML5 structure (`header`, `nav`, `main`, `section`, `footer`)
- Header with store name and a search bar UI
- Category navigation — All, Electronics, Fashion, Accessories
- 6 product cards, each with:
  - Product image
  - Product name
  - Short description
  - Price
  - Rating
  - "Add to Cart" button
- CSS Grid layout for the product cards
- Hover effects and smooth transitions on cards and buttons
- Fully responsive using CSS media queries:
  - 🖥️ Desktop → 3 products per row
  - 📱 Tablet → 2 products per row
  - 📱 Mobile → 1 product per row

## 🛠️ Built With

- HTML5
- CSS3 (Grid, Flexbox, Media Queries)
- No frameworks or libraries
